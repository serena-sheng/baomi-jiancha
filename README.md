# 保密检查

macOS 常驻后台的全盘保密检查工具。装在菜单栏，插上电就自己扫，扫描结果落在本机数据库里，随时打开看。

`v0.1.0` · macOS 13+ · MIT · 完全离线：不联网、不上传、不把内容写进日志

> 从「净盘」抽出来的检查引擎独立成一个项目。净盘管一块 U 盘；保密检查管这台机器上所有能读到的文件。

## 它查什么

只有两类进清单、参与脱密：**国家秘密**（绝密 / 机密 / 秘密）与**工作秘密**。内部资料、证件号、文档属性、照片位置一律不报。

| 类别 | 具体项 |
|---|---|
| 国家秘密标志 | 独立成行、≤40 字、带 ★/☆ 或期限，或密级词就在行首三字内的 绝密 / 机密 / 秘密 |
| 工作秘密 | 同样按「标志」认，单列一级；它是工作秘密，不是国家秘密 |
| 不算的 | 「内部资料 / 内部使用 / 注意保密」这类不再定级；正文里的「绝密级公文应当如何管理」这种叙述也不算 |
| 旧格式 | WPS 的 `.wps/.et/.dps` 与 `.doc/.xls/.ppt`（OLE 复合文档）：先让系统 `textutil` 取一份干净正文再判 |
| 扫描件 | 无文字层的 PDF / 图片／OFD 图片页，用系统 Vision 在设备端识别（中文） |
| 无法检查 | 加密、识别不出、超大、老格式读不到正文的，明确标「未检查」——这是覆盖提示，不是命中 |

## 在清单里处理

扫描过程中就能动手，不必等它跑完：

- 点一行 = 勾选（悬停出现的小箭头才是在访达中定位）
- 每行右侧「脱密」：只处理这一份；底部「脱密选中 N 个」：批量，处理时显示进度并可中止
- 成功后进入「本次处理」区，可「撤销」（原件搬回原位、副本删除、重新检查）；失败可「重试」
- 处理结果落盘，重启后仍能看到并撤销
- 命中多时分页，每页 50 条，底部翻页

处理走的是净盘同一套管线：先产出干净副本并复检，通过后把原件移进 `~/Library/Application Support/保密检查/trash`，副本回原位；任何一步失败就回滚，原件不动。

**原件不会被删**：回收目录里留着，确认没问题后自己清空——那里仍然是原文。

## 菜单栏

图标就是状态：**半盾 = 正在扫**，**勾盾 = 今天扫过**，**空盾 = 还没扫**；命中里有国家秘密标志时，图标右边多一个数字。

点开是：状态行（正在扫描 25,495/91,196 或 空闲 · 已索引 N 个文件）、国家秘密/工作秘密/未检查三个计数、上次完成时间，然后是「打开清单 / 立即扫描（停止扫描）」「空闲 2 小时后自动重扫」「开机自启」。

开机自启第一次运行就会装上（`~/Library/LaunchAgents/com.serena.baomijiancha.plist`），之后在菜单里开关。同时只会有一个进程在跑：开机自启与手动打开撞上时，后启动的那个直接退出。

## 怎么跑得动

- **指纹跳过**：每个文件的 `mtime + size` 存在 SQLite，没变就不重查。第二次启动基本是秒过
- **增量补扫**：FSEvents 监听变更，5 秒合并一次，只重查变更路径所在的目录
- **低优先级**：扫描队列用 `.utility`，不和你抢 I/O
- **排除**：`Library`、`node_modules`、`.git`、`.photoslibrary`、`.app`、回收站等
- **空闲重扫**：每 60 秒看一次系统空闲时间，连续空闲 2 小时且距上次开扫也超过 2 小时，就重新全盘扫一遍

## 权限

要在「系统设置 → 隐私与安全性 → 完全磁盘访问」里勾上本应用，否则 `~/Library/Mail`、`~/Library/Safari` 这类受保护目录读不到。没有权限也能跑，但面板会提示「部分目录没查」——不会把读不到说成干净。

## 安装

```bash
git clone https://github.com/serena-sheng/baomi-jiancha.git
cd baomi-jiancha
./build.sh
open "build/保密检查.app"
```

菜单里点「安装开机自启」会写一个 LaunchAgent（`~/Library/LaunchAgents/com.serena.baomijiancha.plist`）。

命令行只读体检：

```bash
./build/保密检查.app/Contents/MacOS/Baomi --scan ~/Desktop
./build/保密检查.app/Contents/MacOS/Baomi --scan /Volumes/U盘 --json
```

## 数据落在哪

| 内容 | 位置 |
|---|---|
| 索引与命中 | `~/Library/Application Support/保密检查/index.db` |
| 日志（只记路径与类型，不记内容） | `~/Library/Logs/baomi.log` |

卸载：退出应用，删掉上面两项和 `/Applications/保密检查.app`。

## 边界（写进代码，不只是文案）

1. **只读**：本版不改任何文件。脱密在「净盘」里做，这里只负责发现。
2. **不当成干净**：加密文档、读不到的目录、无文字层又 OCR 不出字的扫描件、超 60MB 的文件，都记为「无法检查」，不计入干净。
3. **不改变密级**：软件能指出「这里有密级标志」，不能给文件解密，也不能说它已经可以对外。
4. **不联网**：没有网络代码；OCR 走系统 Vision，模型在设备上。

## 已知限制

- 没有特权 helper：`/System`、其他用户的家目录、SIP 保护的路径不在扫描范围
- 首次全盘扫描可能要几分钟到几十分钟，取决于文件数量与扫描件多少
- 增量依赖 FSEvents，外接磁盘拔掉再插会触发一次补扫
- `.et/.dps` 与 OFD 的正文覆盖在「净盘」里验证过，本版只做读取
