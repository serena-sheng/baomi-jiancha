# 06 · 交互复核（v0.4.0）

**结论**：撤销链仍未通：成功即删行，撤销与失败状态只在内存，重启即无。

**状态**：✓ 点行=勾选/悬停定位、扫描不重排、三态文案、批量份数+中止、失败重试、「全选本页」与分页、计数「（不完整）」。△ 批量无进度条。✗ 成功行、撤销、中止选中、重启、转格式、翻页、扫描中翻页。

**① 撤销（P0）**
现状：成功后 `replaceFindings` 清空命中，`refresh` 只从 findings 取行，行与「撤销」一起消失；`status`、`undoable`、`trashByPath` 只在内存；.doc→.docx 以旧路径作键。原件搬回后指纹仍是脱密前值，`rescan` 判「没变」跳过。风险：撤不掉；还原后的密件仍显示为干净。改法：结果落库、成功行保留到用户关闭、撤销前清指纹强检、转格式记原名。文案：「已脱密 · 原件在回收目录 · 撤销」「撤销会删掉脱密后的副本，把原件移回并重新检查，继续？」

**② 无确认**
现状：行内与批量都直接执行。风险：误点即移走原件，而此时撤销不可达。改法：共用确认框，批量列前三个文件名。文案：「将处理 12 个文件，原件移入回收目录，可撤销。」

**③ 中止**
现状：循环 break 后无条件清空选中，通知仍报「已脱密 N 个文件」。风险：剩余项消失，分不清中止与完成。改法：只移除已处理项，保留其余选中。文案：「已中止：处理 3 个，9 个未动（仍选中）· 继续处理」。

**④ 扫描中**
现状：列表冻结而计数实时涨；有旧行时没有「清单未更新」提示；页脚仍可翻页，页码变而列表不变。风险：旧清单或空翻页被当成全部。改法：扫描时钉一句提示并禁用翻页，完成时报新增。文案：「扫描中 · 清单先不更新，新命中结束后一起显示」「扫描完成 · 新增 12 个文件命中 · 知道了」。

**⑤ 失败**
现状：状态只在内存；开始新任务先清空，抹掉其他行的失败原因与撤销；无失败筛选、无窗内收尾。风险：重启后重试无门。改法：结果落库、按文件失效、头部可筛失败、完成给摘要。文案：「2 个没处理成功，原件没动 · 只看失败」「没成功：PDF 已加密，读不了内容 · 重试」。

**⑥ 翻页**
现状：`goPage` 与「全选本页」都直接重置选中，不提示。风险：跨页挑选时静默丢掉已选，批量范围出错。改法：翻页保留选择，显示跨页数量；「全选本页」替换前说明。文案：「已选 12 个 · 分布在 3 页」「全选本页（50 条），将替换当前已选」。
