# 保密检查 · 规格（v0.1）

## 目标

一台 Mac 上，只要文件落盘，就不需要人工去翻：后台自己扫，命中按等级列出来，点开能看上下文与位置。

非目标：不做脱密（那是净盘的活）、不做合规认定、不做取证固化。

## 用户故事

1. 装好、给完全磁盘访问权限，之后不再管它。
2. 菜单栏图标显示数量；点开是清单：等级、文件、命中类型、一行上下文。
3. 点一行在访达里定位；改过的文件几秒内自动重查。
4. 一周后打开，能回答「这台机器上有没有密级标志」。

## 架构

```
菜单栏 (NSStatusItem)
  └─ Scanner（后台队列，.utility）
        ├─ 枚举：家目录 + /Volumes/*，排除缓存与包
        ├─ 指纹：Store.fileState(path) → mtime+size 未变即跳过
        ├─ 检查：Confidential.inspectFileForCLI（与净盘同一套引擎）
        └─ 入库：findings(path, kind, level, place, value, note, ctx)
  └─ DirWatcher（FSEvents，5 秒合并）→ 只补扫变更目录
  └─ WindowController（SwiftUI 清单）
```

## 数据模型

| 表 | 字段 | 说明 |
|---|---|---|
| `files` | path, mtime, size, scanned_at | 指纹；用于跳过未变文件 |
| `findings` | path, kind, level, place, value, note, ctx, via_ocr, found_at | 一条命中一行；`ctx` 是命中前后 14 字 |
| `meta` | key, value | 预留（上次全盘时间、规则版本） |

`level`：4 绝密 / 3 机密 / 2 秘密 / 1 内部 / 0 提示。

## 性能预算

| 场景 | 目标 |
|---|---|
| 二次启动（无变更） | 文件枚举 + 指纹比对，不读内容 |
| 单文件检查 | 文本 < 10ms；文档 < 80ms；扫描件 OCR 0.3–1s/页 |
| 增量 | 变更后 5–10 秒内入库 |
| 内存 | 不缓存文件内容，只留路径与命中 |

## 权限与降级

- 需要「完全磁盘访问」。检测方式：试读 `~/Library/Mail`，失败则在界面提示并提供跳转按钮。
- 读不到的目录不静默跳过：`Confidential` 会记 denied 计数（本版先只在日志里体现，v0.2 进清单）。

## 安全与隐私

- 无网络代码；不引入任何云 OCR / 云模型。
- 日志只写路径、类型、计数；不写命中值、不写正文。
- 数据库在本机，权限继承用户目录；卸载即清除。
- 不做「自动修复」：读到的内容不改。

## 验收（v0.1）

1. `--scan <目录>` 与常驻扫描对同一目录给出一致结果。
2. 修改一个文件后 10 秒内，数据库里该文件的命中被更新。
3. 新建一个含「秘密★」的 txt，10 秒内出现在清单里。
4. 删掉文件后，记录同步消失（不留幽灵）。
5. 连续跑 30 分钟无崩溃；无权限时界面明确提示。
